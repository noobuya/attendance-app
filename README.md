# 출결 관리 앱

휴대폰에 설치해서 쓰는 출결 관리 앱입니다. 안드로이드는 APK로, 아이폰은 홈 화면 앱으로 설치합니다.

## 기능
- **출결 입력**: 날짜를 고르고 사람마다 출석 / 지각 / 조퇴 / 결석 / 공결 중 하나를 누릅니다. 같은 버튼을 다시 누르면 취소됩니다. "전체 출석"으로 미입력자를 한 번에 출석 처리할 수 있습니다.
- **그룹**: 사람들을 여러 그룹(예: 1반, 2반)으로 나눠서 그룹별로 보고 입력합니다.
- **출결표**: 시작일 ~ 종료일을 정해서 사람 × 날짜 표와 사람별 합계, 출석률을 봅니다. CSV(엑셀)로 내보낼 수 있습니다.
- **그래프**: 같은 기간으로 상태별 비율, 날짜별 출석률, 그룹별 출결, 사람별 출석률을 그래프로 봅니다.
- **관리**: 그룹·사람 추가/수정/삭제, 백업 파일 저장/불러오기, 예시 데이터.

출석률 = (출석 + 지각 + 조퇴 + 공결) ÷ 입력된 출결 수. 기록은 휴대폰 안에만 저장됩니다.

## 설치 파일(APK) 만들기
이 저장소를 GitHub에 올리면 GitHub Actions가 자동으로 APK를 만들어
**Releases → 출결 관리 최신 버전 → 출결관리.apk** 에 올립니다.
휴대폰에서 그 파일을 내려받아 열면 설치됩니다 ("출처를 알 수 없는 앱 설치"를 한 번 허용해야 합니다).

## 아이폰에서 쓰기
아이폰은 Safari로 https://noobuya.github.io/attendance-app/ 를 열고
**공유 버튼 → 홈 화면에 추가**를 누르면 앱 아이콘이 생기고, 인터넷 없이도 앱처럼 열립니다.
(이 주소는 저장소에 올릴 때마다 자동으로 최신 버전으로 바뀝니다.)
기록은 그 아이폰 안에만 저장되니, 가끔 관리 탭에서 백업 파일을 저장해 두세요.

## 구조
- `www/` 앱 화면 (HTML/CSS/JS, 그래프는 Chart.js)
- `android/` Capacitor 안드로이드 프로젝트
- `.github/workflows/android.yml` APK 자동 빌드
- `.github/workflows/pages.yml` 아이폰용 웹앱 배포 (GitHub Pages)

## 직접 빌드할 때
Node 20, JDK 17, Android SDK가 있으면:
```
npm ci
npx cap sync android
cd android && ./gradlew assembleRelease
```
